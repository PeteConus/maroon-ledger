# The Maroon Ledger

An independent guide to the Queensland State Budget: where the money comes from, where it goes,
what changed, how forecasts have tracked against outcomes, where the State plans to build, and
what each portfolio spends and promises to deliver.

It covers 2021–22 to 2029–30: actual outcomes from the Reports on State Finances, the 2025–26
estimated actual, the 2026–27 Budget and its projections. Every figure is read from an official
Queensland Treasury, Queensland Government open data or Australian Bureau of Statistics source
by a script in this repository, and checked before it reaches the site.

Not a Queensland Government publication. Made by Conus Business Consultancy Services, Far North
Queensland.

## Viewing it

Live site: https://peteconus.github.io/maroon-ledger/

To run it offline, download or clone this repository and open `site/index.html` in any modern browser. It needs no
server and no installation, and works offline (web fonts fall back to system fonts).

## What is where

```
site/                 the website (10 pages)
  assets/data.js      the dataset the site reads, generated by the pipeline
  assets/icons/       favicons and app icons
pipeline/
  build_data.py       reads every source and writes site/assets/data.js and pipeline/out/
  extract_rsf.py      Reports on State Finances (actual years)
  extract_bp2.py      2026-27 Budget Paper 2 (2025-26 onwards)
  extract_sds.py      2026-27 Service Delivery Statements (portfolios and HHSs)
  extract_other.py    MYFER reconciliation, past Budgets (open data), BP3 regions, ABS
  parse_lib.py        shared PDF-table helpers
  build_pages.py      writes the HTML page shells
  sources/            every source document, kept so the build re-runs offline
  out/                tidy CSVs of every dataset, and validation.txt
```

## Rebuilding the data

Needs Python 3 with `openpyxl`, and `pdftotext` (poppler-utils).

```
cd pipeline
python3 build_data.py      # prints: N checks, M flagged
python3 build_pages.py
```

The live site is served from the `gh-pages` branch, which holds the contents of `site/` only
(`git subtree split --prefix site -b gh-pages`, then push that branch).

Read `pipeline/out/validation.txt` after every rebuild. Each check confirms that a breakdown adds
to its published total, that the same figure agrees across documents, or that a value extracted
from a PDF appears on the source line. A FLAG means the published figures themselves do not add
up; those are disclosed on the site's Sources page rather than adjusted.

A handful of values the PDF layout defeats are transcribed by hand in `extract_sds.py`
(`MANUAL`, `STAFF_FIX`), each labelled on the site.

### Next updates

- **2025-26 Report on State Finances** (usually tabled late October): save it as
  `pipeline/sources/RSF-2025-26.pdf`, add `"2025-26"` to `RSF_YEARS` in `extract_rsf.py`, remove
  `"2025-26"` from `FWD` in `extract_bp2.py` (leave `ALL_FWD`), delete the `"2025-26": "estimate"`
  entry in `STATUS` in `build_data.py`, then rebuild. ABS 2025-26 nominal GSP arrives in November;
  until then the build stops with a missing-key error for 2025-26 GSP, which is deliberate.
- **2027-28 Budget** (June 2027): point the extractors at the new Budget Papers 2 and 3 and the new
  Service Delivery Statements, rebuild, and read every SDS line in `validation.txt`.
